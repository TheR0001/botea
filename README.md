# Botea

Botea est un robot discord français développé en python.

# Ajouter le bot 

Pour ajouter le bot à votre serveur, cliquez [ici](https://discord.com/oauth2/authorize?client_id=1346009441274826834&permissions=8&integration_type=0&scope=bot+applications.commands)

# Commandes

Le préfixe des commandes est "!".
Pour accéder à toutes les commandes entrez la commande ```!help```.
